# spark-cost-aware-optimization

A Cost-Aware Decision Framework for Adaptive Optimization of Apache Spark Data Pipelines
M.Sc. Research Project — Mustaqeem Shaikh

## Required Python version: 3.11 (Python 3.13 will NOT work)

PySpark 3.5.1 does not support Python 3.13 -- this is a confirmed, hard
incompatibility on Windows (a known internal API PySpark relies on,
`socketserver.UnixStreamServer`, was changed in 3.13), not something fixable
via pip pinning. If `python --version` shows 3.13.x, install Python 3.11
alongside it (do not remove 3.13) from
https://www.python.org/downloads/release/python-3119/, then build the venv
with `py -3.11 -m venv venv` specifically. This is now a documented hard
requirement for this project -- see `environment.md` for the exact version
this study was run on.

## Windows users: event logging is OFF by default (and that's fine)

Spark's event log requires a Windows-only helper binary (`winutils.exe`) that
isn't part of a normal PySpark install, and it isn't needed for anything in
this study — your actual metrics come from `sparkmeasure` (Phase 5), which
attaches directly to the live session. `spark_config.py` reflects this:
`enable_event_log=False` by default.

**Only if you want the Spark History Server UI** (not required for any
experiment here), you can enable it:
1. Download `winutils.exe` and `hadoop.dll` matching Hadoop 3.3.x from
   https://github.com/cdarlint/winutils (community-maintained, widely used).
2. Place both files in `C:\hadoop\bin`.
3. Set a system environment variable `HADOOP_HOME=C:\hadoop`, and add
   `%HADOOP_HOME%\bin` to your `PATH`.
4. Copy `hadoop.dll` into `C:\Windows\System32` as well (avoids a separate,
   common native-library loading error on Windows).
5. Restart your terminal, then pass `enable_event_log=True` when calling
   `get_spark_session()`.

## Setup (run these in order, on YOUR machine)

```bash
# 1. Create and activate a virtual environment
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 2. Install pinned dependencies
pip install -r requirements.txt

# 3. Confirm Java is installed (JDK 11 or 17)
java -version
# If missing, install one (e.g. https://adoptium.net) before continuing.

# 4. Generate environment.md for YOUR machine's real specs
python3 src/environment_report.py
# Then open environment.md and manually confirm the disk-type line.

# 5. Run the full Phase 2 verification suite
python3 src/verify_phase2_setup.py
# Must print "PHASE 2 COMPLETE" before you proceed to Phase 4.
```

## Non-negotiable rules for this project

1. **Every SparkSession is built through `src/spark_config.py`'s `get_spark_session()`.**
   Never call `SparkSession.builder` directly in an experiment script — that's how
   configuration drift between runs happens silently.

2. **`spark.sql.adaptive.enabled` stays `False` for all A1 experiments.**
   This is enforced by the default in `get_spark_session()` — don't override it
   without a documented reason.

3. **`experiment_results.csv` (created in Phase 5/6) is append-only, script-written.**
   Never hand-edit a results file. If a run is bad, mark it bad in a `notes` column —
   don't delete or silently fix a row.

4. **`baseline_pipeline.py`'s logic is frozen once experiments begin (Phase 6).**
   If it must change, that's a new pipeline version — old and new results are not
   comparable, and this must be stated explicitly if it happens.
