# Paper

IEEE conference paper (IEEEtran) for CAO-DF.

| Path | Content |
|---|---|
| `main.tex` | Preamble, title, author block, section includes |
| `sections/` | One file per section (`00_abstract` … `10_backmatter`) |
| `references.bib` | Bibliography; every entry checked against Crossref/arXiv/publisher pages |
| `figures/` | Figures generated by the analysis scripts |

Red `\tbd{...}` markers show content that depends on later phases (cost model, framework
validation, analysis).

## Building

**Overleaf:** upload the `paper/` folder and compile `main.tex` with pdfLaTeX.

**Local:** with a TeX distribution (MiKTeX or TeX Live) installed:

```
cd paper
latexmk -pdf main.tex
```

or `pdflatex main`, `bibtex main`, `pdflatex main`, `pdflatex main`.
